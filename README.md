# 宗申动力股价监控

当 **宗申动力（001696.SZ）** 跌到 **14.55 元**附近时，自动把消息推送到微信。

跑在 GitHub 的服务器上，**不占用你的电脑**——关机、断网、睡觉都照常工作。

---

## 工作原理

```
GitHub Actions（云端定时）
      │  工作日 9:35 / 10:35 / 11:35 / 13:35 / 14:35 / 15:35
      ▼
check_stock.py  取实时价（腾讯 → 新浪 → 东财，三源兜底）
      │
      ├─ 现价 > 14.55  → 什么都不做
      ├─ 现价 ≤ 14.55  → 推送微信（Server酱），并记下"已提醒"
      └─ 现价 ≥ 14.80  → 复位，下次跌破才会再提醒
      ▼
state.json 记录提醒状态，提交回仓库，跨次运行不会重复刷屏
```

### 几个设计上的取舍

| 问题         | 处理方式                  | 为什么                        |
| ---------- | --------------------- | -------------------------- |
| 节假日误报      | 行情日期 ≠ 今天 就跳过         | 否则休市时会拿上一交易日的收盘价反复报警       |
| 重复刷屏       | 触发线 14.55 / 复位线 14.80 | 价格在 14.5 下方横盘时只提醒一次        |
| 海外服务器取不到数据 | 腾讯、新浪、东财三个源依次尝试       | GitHub 服务器在境外，单一接口可能不通     |
| 定时任务被静默关停  | 每月强制写一次 state.json    | GitHub 会在仓库 60 天无提交后停掉定时任务 |
| 提交记录太吵     | 只在状态翻转时写盘             | 否则每天多出 6 条无意义提交            |

## 推送渠道

程序会按 **Server酱 → pushplus → WxPusher** 的顺序，自动挑选第一个已配置凭据的渠道。配一个就够。

| 渠道 | 免费额度 | 获取方式 | 收消息的地方 |
|---|---|---|---|
| **Server酱**（推荐） | 5 条/天 | GitHub 账号登录 <https://sct.ftqq.com> → 「SendKey」页面复制 | 微信，关注「方糖服务号」即可 |
| pushplus | — | 2026-09 起免费用户要付费实名 | 微信 |
| WxPusher | 2000 条/天 | 扫码得 SPT | **必须装 WxPusher 客户端 App** |

> **关于 WxPusher（实测教训）**：它的 SPT 极简推送只会投递到自家客户端 App，
> 微信公众号已降级为补充通道。**没装 App 时消息会永久卡在「等待发送」状态**，
> 接口却返回 `code:1000 处理成功`——典型的静默失败，很容易误以为已经发出去了。
> 所以我们改用 Server酱。

> **密钥别外泄**：SendKey / SPT 相当于你的收件地址，泄露了任何人都能给你发消息。
> 它只存在于 GitHub 仓库的 Secrets 里，不会写进代码文件。

## 部署

### 方式一：一键脚本（推荐）

在仓库根目录执行：

```bash
export GH_TOKEN=ghp_xxx          # 需要 repo + workflow 权限
export SERVERCHAN_KEY=SCTxxx     # Server酱的 SendKey
python tools/deploy_to_github.py  # 建仓库、传代码、配密钥、跑首次验证
```

脚本走的是 `api.github.com`，不走 `github.com`——后者在国内经常时通时断。

### 方式二：手动五步

1. 新建 GitHub 仓库，名字随意（如 `stock-alert`），**Public 或 Private 都可以**
2. 在仓库里新建文件 `.github/workflows/stock-alert.yml`，内容见本仓库同名文件
3. 在仓库里新建文件 `check_stock.py`，内容见本仓库同名文件
4. 仓库 `Settings` → `Secrets and variables` → `Actions` → `New repository secret`
   - Name 填 `SERVERCHAN_KEY`
   - Secret 填你的 SendKey
5. 仓库 `Actions` 标签页 → 选「宗申动力股价监控」→ `Run workflow` 手动跑一次

> 想换成别的渠道，把 secret 名字改成 `PUSHPLUS_TOKEN` 或 `WXPUSHER_SPT` 就行，程序自己认。

### 随时自测推送链路

```bash
SERVERCHAN_KEY=SCTxxx python check_stock.py --test
```

只发一条测试消息，不连行情源、不写状态文件，可以反复跑。

## 改参数

打开 `check_stock.py`，改最上面这几行即可：

```python
CODE    = "001696"   # 股票代码，换成别的股票就改这里
NAME    = "宗申动力"
TRIGGER = 14.55      # 触发线：现价 ≤ 这个数就提醒
RESET   = 14.80      # 复位线：价格回到这个数以上，下次跌破才会再提醒
```

`CODE` 换成别的 A 股代码就能监控其它股票。

## 已知限制

- **定时精度**：GitHub 的 cron 在高峰期可能延迟几分钟到几十分钟，不保证准点。抓不到盘中瞬间插针又拉回的价位。
- **非交易日不判价**：周末和法定节假日不会推送（这是有意设计，避免误报）。
- **只监控一个价位**：跌破 14.55 提醒一次，不会在 14.0、13.5 再提醒。需要分档提醒的话要另加逻辑。
